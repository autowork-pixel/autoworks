# 오토웍스 마케팅 자동화 웹

기존 로컬 자동화 기능을 월 구독형 웹 서비스로 전환하기 위한 베타 웹입니다.

## 미리보기

index.html을 브라우저에서 엽니다. 메뉴에서 대시보드, 도구 목록, API 연결 준비 상태, 기존 요금제를 확인할 수 있습니다. 작은 화면 메뉴도 지원합니다.

## 현재 범위

- 현재 설정에 있는 AI 막내(월 199,000원), AI 대리(월 359,000원), AI 팀장(월 599,000원) 표시
- 기존 여섯 실행 모듈과 별도 AI 블로그 스튜디오의 구현 위치를 기준으로 기능 상태 표시
- 네이버 SEO 점유 분석은 원본 README에서 아직 실행 코드 전 단계로 표시
- 네이버, OpenAI, YouTube, Apify, Google Sheets 연동 항목 표시
- Firebase Hosting, Google 로그인, 고객별 워크스페이스와 프로젝트 저장·재조회 연결
- 고객별 최근 실행·월 사용량·최근 결과를 읽는 대시보드 영역 준비
- 고객 API 키의 서버 암호화 저장, 네이버·카카오 로그인, 결제, 실제 서버 실행은 아직 연결되지 않음

## 다음 구현 단계

1. 실제 계정 두 개로 프로젝트와 고객별 읽기 권한 격리를 검증합니다.
2. Cloud Run·Billing 범위를 정하고 서버가 Firebase ID 토큰과 워크스페이스 소유권을 확인하게 합니다.
3. API 키를 브라우저 저장소에 두지 않고 서버에서 고객별로 암호화 저장합니다.
4. 기존 로컬 기능을 서버 작업으로 하나씩 옮기고 실행 결과와 오류를 고객 계정에 귀속합니다.
5. 토스페이먼츠 정기결제를 연결하고 구독 상태에 따라 요금제 기능을 제한합니다.

결제 키, 법인/사업자 설정, 계정·DB 제공자, 배포 도메인이 정해지기 전까지는 가입·청구를 실행하지 않습니다.
