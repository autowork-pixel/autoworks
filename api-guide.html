사용할 기능에 필요한 서비스만 골라 연결하세요. 계정 만들기, API 사용 설정, 키 복사, 오토웍스 등록 순서로 안내합니다. 화면 그림을 누르면 크게 볼 수 있어요.

먼저 확인하세요. 제공자 계정과 사용 요금은 오토웍스 구독과 별도일 수 있습니다. 특히 ChatGPT 구독에는 OpenAI API 사용료가 포함되지 않으며, Higgsfield 웹 구독과 API 잔액도 서로 다릅니다. 키는 문의나 채팅으로 보내지 말고, 오토웍스의 보안 연결 화면에만 입력하세요.

API 키를 안전하게 관리하는 방법

오토웍스는 키를 입력할 때 연결 테스트 결과만 보여주고 키 원문은 다시 표시하지 않는 방식으로 구현합니다. 키 입력 전에는 필요한 권한과 과금 주체를 확인하고, 연결을 해제하거나 제공자 콘솔에서 키를 폐기하면 더 이상 사용할 수 없습니다.

제공자 콘솔 화면과 메뉴 이름은 변경될 수 있습니다. 최신 발급 방법은 각 공식 가이드에서 확인해 주세요.
