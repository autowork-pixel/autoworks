오토웍스 이용 안내

브랜드 분석부터 콘텐츠 업무까지, 필요한 기능을 순서대로 연결합니다.

서비스 준비 중 · 2026년 10월 24일 기준

현재 웹은 미리보기 단계입니다. 회원가입, API 연결, 정기결제 및 실제 분석 기능이 준비되면 이 안내를 실제 화면에 맞춰 업데이트합니다.

처음 이용할 때

  1. 계정을 만드세요

    이메일과 로그인 정보를 등록하고, 이용약관과 개인정보 처리 안내를 확인합니다.

  2. 필요한 요금제를 선택하세요

    AI 막내·AI 대리·AI 팀장 중 필요한 자동화 범위를 확인하고 월 구독을 신청합니다. 다음 결제일과 과세 금액은 결제 전에 표시됩니다.

  3. 사용할 외부 API를 연결하세요

    OpenAI, 네이버, YouTube, Apify 등 기능에 필요한 API 키를 고객 계정에서 연결합니다. 전체 키가 담긴 화면을 공유하거나 문의에 첨부하지 마세요.

  4. 분석 조건을 입력하고 실행하세요

    브랜드, 주제어, 비교 대상, 기간, 채널과 필요한 입력 자료를 확인한 뒤 분석을 시작합니다. 고객 데이터가 포함된 파일은 사용 권한을 확인한 자료만 올려 주세요.

  5. 결과를 검토하고 저장하세요

    수집 시각, 검색 조건, 원본 데이터와 분석 결과를 확인하세요. AI 결과와 자동 분류는 오류가 있을 수 있으므로 외부 발행·발송 전에 직접 검토해야 합니다.

도구별 입력 준비

  • 인플루언서 후보 찾기: 브랜드·주제어, 채널, 목표 후보 조건과 YouTube/Instagram 관련 API.
  • 화제 콘텐츠 레퍼런스: 검색 주제어, 콘텐츠 채널과 공개 게시물 수집 API.
  • 협업 게시물 성과 조회: 확인할 브랜드·게시물 정보와 채널 API.
  • 브랜드 검색량 추이: 브랜드명과 네이버 검색광고 API.
  • 주간 광고 분석: Excel 또는 Google Sheets 광고 데이터.
  • AI 블로그 스튜디오: 주제·브랜드 사실·키워드와 OpenAI API.

기능별 요구 권한과 입력 형식은 연결 화면에서 다시 안내합니다. 이 목록은 기존 자동화 코드와 설정에서 확인한 준비 항목입니다.

외부 공유와 자동 실행

분석 결과를 이메일이나 메신저로 보내거나, 게시물을 발행하거나, 광고 설정을 변경하는 기능은 고객이 별도로 요청하고 확인한 경우에만 실행합니다. 현재 미리보기는 실제 데이터를 수집하거나 외부로 전송하지 않습니다.

문제가 생겼나요?

오류가 난 기능명, 발생 시각, 입력 조건과 화면에 표시된 오류 문구를 적어 고객센터로 문의해 주세요. API 키 원문이나 결제 카드정보는 보내지 마세요.
