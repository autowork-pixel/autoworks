무엇을 도와드릴까요?

계정, API 연결, 분석 결과와 구독 결제에 대해 문의해 주세요.

상담 시간은 문의 후 회신으로 안내합니다.

현재는 서비스 미리보기 단계라 실제 계정·결제 문의를 처리할 수 없습니다. 정식 고객 기능이 열리면 아래 문의 창구를 운영합니다.

자주 묻는 질문

회원가입이나 로그인이 되지 않아요.

가입에 사용한 이메일과 로그인 방식을 확인해 주세요. 가입 확인 메일이 보이지 않으면 스팸함도 확인한 뒤 문의해 주세요.

어떤 API 키를 연결해야 하나요?

사용할 도구에 따라 OpenAI, 네이버 검색·검색광고, YouTube Data API, Apify 등의 키가 필요할 수 있습니다. 각 기능 화면에서 필요한 키와 권한을 안내합니다. API 제공자의 사용료와 호출 한도는 고객 계정과 계약에 따라 다를 수 있습니다.

API 키가 저장되지 않거나 오류가 나요.

연결 대상 서비스에서 키가 유효한지, 필요한 권한·사용량 한도가 있는지 먼저 확인해 주세요. 문의에는 키 원문 대신 연결 서비스 이름, 오류 시각과 문구만 포함해 주세요.

월 구독을 해지하면 바로 이용이 끝나나요?

정식 오픈 후 구독 관리 화면에서 해지할 수 있으며, 해지 시점과 남은 이용기간은 계정 화면에 표시합니다. 결제·취소 및 환불 기준은 환불정책에서 확인해 주세요.

분석 결과가 맞지 않는 것 같아요.

검색어·기간·채널과 외부 데이터 제공 시각을 확인해 주세요. 자동 수집이나 AI 분류 결과는 사람이 검토해야 하며, 오류가 있는 결과와 실행 조건을 함께 알려주시면 확인하기 쉽습니다.

계정과 자료를 삭제하고 싶어요.

계정 설정 또는 고객센터를 통해 탈퇴·삭제를 요청할 수 있도록 제공할 예정입니다. 거래 보관 의무가 있는 정보는 법정 기간 동안 분리 보관될 수 있습니다. 자세한 기준은 개인정보처리방침을 확인해 주세요.
