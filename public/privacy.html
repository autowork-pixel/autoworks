개인정보처리방침

오토웍스의 계정, 마케팅 자료, API 연결과 구독 정보를 어떻게 처리하는지 안내합니다.

시행 예정일: 정식 베타 공개 전 확정

현재 개발 서비스는 Google 로그인 계정 식별값, 고객 워크스페이스·프로젝트와 문의를 Firebase에 저장할 수 있습니다. 네이버 검색광고 API 키는 KMS 보안 서버가 연결된 환경에서만 고객이 직접 저장·교체·삭제하도록 구현했으며, 현재 공개 Hosting에는 해당 서버를 연결하지 않았습니다. 결제·파일 업로드와 실제 자동화 실행도 아직 공개하지 않았습니다. 초대 베타 전 인증·호스팅·저장 수탁자, 국외 이전과 보호책임자 연락처를 확정해 이 방침을 갱신합니다.

1. 처리하는 정보와 목적

계정 정보이메일, 표시 이름, 계정 식별값, 로그인·보안 기록. 가입, 인증, 계정 관리와 부정 이용 방지.
구독·거래 정보선택한 요금제, 구독 상태, 주문·결제 식별값, 승인·취소 금액과 시각. 구독 제공, 결제 확인, 취소·환불과 분쟁 처리.
API 연결 정보고객이 연결한 외부 API 키와 연결 대상·상태. 요청한 자동화 실행. 운영 시 키는 암호화 저장하도록 설계하며, 현재 화면은 키를 받지 않습니다.
입력 자료와 결과주제어, 브랜드·키워드, 업로드한 표·자료, 실행 내역과 결과물. 고객이 요청한 분석·콘텐츠 기능 제공과 오류 대응.
문의·기술 기록문의 이메일과 내용, 기기·브라우저, 접속·오류·보안 기록. 상담, 서비스 안정성·보안 유지.

2. 외부 서비스와 처리 위탁

서비스 오픈 시점에는 실제 이용하는 로그인·호스팅·데이터 저장·파일 저장·분석 도구와 각 수탁자의 업무, 저장 국가, 보유기간을 이곳에 공개합니다.

  • 토스페이먼츠: 정기결제 신청·승인·취소와 거래 상태 처리. 카드 정보는 토스페이먼츠 결제 화면에서 처리하도록 연동하며 운영자가 전체 카드번호나 보안코드를 저장하지 않도록 구성합니다. 계약과 실제 연동 완료 후 세부 항목을 갱신합니다.
  • 고객이 선택한 API 제공자: 고객이 실행을 요청한 경우, 필요한 키워드·문안·표 데이터가 고객이 연결한 OpenAI, 네이버, YouTube, Apify 등으로 전송될 수 있습니다. 제공자의 보관·이용 조건과 처리 위치는 고객이 해당 제공자와 체결한 설정과 정책에 따르며, 지원 제공자와 전송 항목은 기능별로 실행 전에 안내합니다.

고객의 API 키는 외부 제공자에 대한 고객 계정 자격증명입니다. 운영자는 고객 동의와 실행 요청 범위를 넘어 키를 사용하지 않으며, 키 원문을 일반 문의 채널로 요청하지 않습니다. 실제 운영사의 하위 처리업체와 국외 이전은 기능 및 저장소를 확정한 후 공개합니다.

3. 보유 기간과 파기

계정 및 서비스 자료는 계정 이용 기간 동안 보유합니다. 탈퇴 또는 삭제 요청이 확인되면 즉시 새 실행을 차단하고 API 키는 24시간 이내, 계정·프로젝트·실행·결과는 7일 이내 삭제하며 백업 사본은 30일 이내 만료합니다. 운영·보안 로그는 90일, 일반 문의는 1년 보유합니다. 표시·광고 기록은 6개월, 계약·청약철회 및 결제·공급 기록은 5년, 소비자 불만·분쟁 기록은 3년간 다른 이용 데이터와 분리 보관한 뒤 파기합니다.

전자 파일은 복구할 수 없는 방식으로 삭제하고, 별도 보존 의무가 있는 기록은 일반 이용 데이터와 분리합니다. 탈퇴 이후에도 법적 보존 기록은 정해진 기간 동안 남을 수 있습니다.
